# FAHMI OMER — Website

## Structure
- index.html — الرئيسية
- about.html — من أنا
- portfolio.html — الأعمال + الفلاتر
- services.html — الخدمات
- contact.html — التواصل
- css/style.css — جميع التنسيقات في ملف واحد قابل للتعديل
- js/site.js — التفاعل، الوضع الليلي، القائمة، الفلاتر، النموذج، العودة للأعلى
- js/i18n.js — اللغات

## المميزات
- وضع ليلي/فاتح مع حفظ الاختيار.
- تصميم متجاوب للجوال والكمبيوتر.
- قائمة جوال.
- تحديد الصفحة الحالية في شريط التنقل.
- فلترة أعمال Portfolio.
- تأثيرات ظهور أثناء التمرير.
- زر العودة للأعلى.
- دعم العربية والإنجليزية، مع إبقاء الصينية والإسبانية جاهزة للتوسعة.
- نموذج التواصل يفتح تطبيق البريد باستخدام mailto.
